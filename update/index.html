Deployment Guide

如何部署网站并生成二维码

此简历网站为纯 HTML + CSS 实现。

部署步骤：

  1. 保存文件：将此代码保存为 index.html 文件
  2. GitHub Pages 部署：
    • 创建一个 GitHub 仓库（如：taohongxi-resume）
    • 将 index.html 上传到仓库
    • 在仓库设置中开启 GitHub Pages 功能
    • 访问地址：https://[用户名].github.io/taohongxi-resume
  3. 生成二维码：
    • 部署后获取在线 URL
    • 使用在线二维码生成工具（如：草料二维码）
    • 输入在线 URL 生成二维码图片
